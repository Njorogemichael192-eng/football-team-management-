# Football Team Manager - Project State

## Current development phase
Phase 16: Full CRUD implementation and project verification.

## Completed features
- Kotlin Android project using Jetpack Compose and Material 3
- Ktor backend module with MongoDB Atlas access
- Player model and position restrictions
- REST CRUD endpoints for players
- Compose list, add, details, and edit screens
- Case-insensitive player-name search
- Client-side form validation and basic network/server error messages
- README setup and build documentation

## Known problems
- MongoDB-backed backend verification requires a valid `MONGODB_URI`.
- Android emulator/device API URL may need to be changed from `10.0.2.2` for a physical device.
